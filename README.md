# dsh-startup-secret

DSH 的启动界面与启动动画插件（二次创作版）。

长征机主题开机动画：黑幕徽章标识 → 过曝洗白 → 暗色「技术档案」底板 →
五步交互式访问授权 → 色散故障揭幕。右下角配赛博电子风人物立绘（可切换，也可设为「空」）。
播放方式可三档设置：完全自动播放 / 仅需点击一次进入 / 不自动播放。
安装后首次启动还会弹出一次「降世」事件窗口（可在设置里改成每次都弹）。

> 本作品为二次创作，仅用于学习交流，没有任何商业用途。如有侵权，请联系移除。

## 功能

**开机序列**　冷启动时播一段完整的开机动画，六幕连贯：厂牌标识 → 过曝洗白 →
暗色底板 → 五步授权 → 揭幕。中央一圈环形准星缓慢自转，缺口留在正下方，
不会挡住底部文字。

**可交互，不是播片**　第一、二步要你点按钮或按 Enter 才会继续（可以关掉）。
右上角有跳过按钮，Esc 也能跳。

**访问密码（可选）**　可在设置页为第二步「身份资料确认」设置访问密码，
密码输对才能继续，输错会提示并停留在原地。密码留空则不启用。

**中文主字 + 英文等宽副标题**　英文副标题逐字打出来，像终端在接收数据。

**赛博电子风人物立绘（可切换）**　从第一步授权起，右下角亮出人物形象，带霓虹辉光
呼吸与偶发信号抖动。设置页「视觉」板块可在 4 款立绘之间切换，风格贴合赛博电子质感。

**事件窗口（可选）**　动画全部结束后，会在主界面中央弹出一张事件图片窗口，提示
「向前！向前！向前！ / 按下 Enter 进入」。按 Enter 或点击窗口任意处即可进入主界面；
设置页「视觉」板块可开关。无任何操作 20 秒后也会自动放行，避免卡死挡住主界面。

**真声台词 + 界面音效**　五句台词和终幕欢迎语都是真声素材，界面音效取自同一段素材。
浏览器要求先有一次点击才准出声，所以点过按钮之后才会听到声音。

**语音没播完不会推进**　每一步停留多久由实际音频时长决定。你点得快也不会把语音掐断。

**三十余项设置**　身份名称、编号、权限等级、访问密码、人物立绘、事件窗口、
配色、速度、音色、语速、开口留白、每处文案……都能在设置页实时改，改完立即生效。

## 安装

**推荐用脚本安装**（脚本会自动完成下面两步，避免漏掉关键步骤）：

- **Windows**：解压后**双击「安装.cmd」**
- **macOS / Linux**：`./install.sh`（可加参数 `./install.sh desktop` 装到桌面端）

### 手动安装（两步，缺一不可）

DSH 加载插件依赖 `dsh.profile.bundles` 层堆栈，但 `dsh plugin add` 只是
`pnpm add` 的转发，**只写 dependencies、不会自动把包名加入 bundles**。
漏掉第二步，插件会"装上了但完全没效果"（不报错、无动画、设置页无入口）。

**第 1 步：安装依赖**

```bash
dsh plugin --profile web add ./dsh-startup-secret-1.3.1.tgz
```

**第 2 步：把插件加入 bundles**（关键）

打开 `~/.dsh/profiles/web/package.json`，在 `dsh.profile.bundles` 数组里加入
`"dsh-startup-secret"`：

```json
"dsh": {
  "profile": {
    "bundles": [
      "@deepseek-ai/dsh-base",
      "@deepseek-ai/dsh-web-app",
      "dsh-startup-secret"
    ]
  }
}
```

（desktop profile 同理，文件在 `~/.dsh/profiles/desktop/package.json`。）

**装完重启 dsh web**（关掉启动器窗口再重新双击）。重启后刷新页面就能看到启动动画，
设置页里会多出一项「启动动画」。

### 环境要求

| 项 | 要求 |
|---|---|
| 平台 | DSH **web** profile 与 **desktop** profile |
| Node | **>= 20** |
| 依赖 | 无（不需要 `npm install`） |

### 卸载

```bash
dsh plugin --profile web remove dsh-startup-secret
```

## 设置选项

装好后进入 **DSH 设置页 →「启动动画」**。

### 播放

| 选项 | 默认 | 作用 |
|---|---|---|
| 启用 | 开 | 总开关，关掉就完全不播 |
| 显示模式 | 每次打开都播放 | `每次打开都播放` 每次启动 DSH 播一次 / `每天一次` 一天只播一次 |
| 主题 | 暗色 | `暖白` 参考片原色 / `暗色` 暗底板 |
| 速度 | 1× | 整段动画的快慢，0.35 – 3 倍 |
| 自动播放 | 完全自动播放 | 三档：`完全自动播放`（全程不停、无需操作）/ `仅需点击一次进入`（开头停一次，需空密码）/ `不自动播放`（第 1、2 步都等确认，即旧版「需要人工确认」）。旧配置的 `requireInteraction` 会自动迁移 |
| 允许跳过 | 关 | 是否显示右上角跳过按钮、是否响应 Esc |

### 身份资料

| 选项 | 作用 |
|---|---|
| 身份名称 | 终幕「欢迎 xxx 访问」里的名字 |
| 身份编号 | 第二步身份卡上的编号，建议填数字 |
| 权限等级 | 第二步身份卡上的权限等级 |
| 访问密码 | 第二步「身份资料确认」的访问密码；留空则不启用密码校验 |

### 语音

| 选项 | 默认 | 作用 |
|---|---|---|
| 语音播报 | 开 | 是否念台词 |
| 语音来源 | 真声素材 | `真声素材` 用内置录音 / `系统 TTS` 用浏览器合成音 |
| 音色 | 自动（优先神经网络女声）-US | 五个内置真声音色，选音色即决定语种与嗓音 |
| 音量 | 0.9 | 台词音量 |
| 播报前提示音 | 开 | 念台词前先响两声轻提示，更像系统播报 |

内置五个音色（均为随包内联的真声素材，无需联网）：

| 音色选项 | 说明 |
|---|---|
| 自动（优先神经网络女声）-US | 英文神经网络女声，默认 |
| 智性少女音-CN | 中文少女音 |
| 清冷优雅-日语 | 日语女声 |
| 威严铿锵宣示-朝鲜语 | 朝鲜语男声播报 |
| 清冷脆弱-俄语 | 俄语女声 |

### 界面音效

| 选项 | 默认 | 作用 |
|---|---|---|
| 界面音效 | 开 | 文字出现、阶段推进、按钮确认的「哒」声 |
| 音效音量 | 0.5 | 界面音效音量（不影响台词） |
| 音效来源 | 内置素材 | `内置素材` 用录音 / `现场合成` 用代码合成 |

### 视觉

| 选项 | 默认 | 作用 |
|---|---|---|
| 强调色 | `#c70000` | 阶段条、进度条、准星的红 |
| 故障色 A / B | `#ff3b30` / `#ce0912` | 揭幕那下色散故障的红 |
| 人物立绘 | 第 1 款（默认） | 在 5 款赛博电子风立绘之间切换；最后一项「空」= 不显示立绘（`mascot: -1`） |
| 降世事件窗口 | 关 | 勾选后每次动画结束都弹事件窗口（按 Enter / 点击进入）；不勾选时只在安装后的首次启动弹一次 |
